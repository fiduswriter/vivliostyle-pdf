list-style-image computed-style probe

  • via stylesheet rule

getComputedStyle(li).listStyleImage = …
getComputedStyle(li, '::marker').listStyleImage = …

Open this file directly in Chromium (or any modern browser). If the values show url("data:image/png;base64,..."), the property IS exposed in computed style. It only reads blank while the image is still loading or failed to resolve.

Note: this library's emitter walks the vivliostyle-paginated DOM, and vivliostyle neutralizes list-style-* to none there, so the emitter still cannot currently read image markers from the paginated layout — a vivliostyle-pagination behavior, not a Chromium one.
